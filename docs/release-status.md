# Release evidence (Pi 1.4.0, 2026-10-25)

This is a development smoke report, **not** a v0.1/v0.2 release approval. Supported/tested host: Pi **1.4.0 only**, Node >=22.19. No claim for later or earlier Pi versions. Automatic repair stays off by default. Requirements/product acceptance remains `not_evaluated` even when verification passes; protected CI checks remain authoritative.

## Clean pinned-source smoke and rollback

A fresh `PI_CODING_AGENT_DIR` and `PI_PACKAGE_DIR` were used to run `pi install git:github.com/kevin-rieck/pi-tuedern@77ae94a`. `pi list` displayed that ref and checkout HEAD was `77ae94a`. The isolated directory has no provider credentials, so a print-mode model run there failed with “No API key found”; an RPC run in that isolated environment then discovered the installed `/verify` command, invoked it against the React fixture, and produced a passing attempt and task summary without requiring a model. Repeat using `node tests/install-smoke.mjs git:github.com/kevin-rieck/pi-tuedern@7e7a23d` (the command installs the pinned source in fresh directories). The same checkout also loaded in an authenticated print-mode run with no extension errors. The package is private and no immutable npm release exists. This is a pinned Git commit, not a release with provenance.

For a trusted project, install with `pi install --local git:github.com/kevin-rieck/pi-tuedern@77ae94a` only after reviewing the commit. Upgrade by replacing the pinned commit explicitly and rerunning `npm run verify`, fixture scripts, and CI. Roll back via `pi remove --local git:github.com/kevin-rieck/pi-tuedern@<new-ref>` then `pi install --local git:github.com/kevin-rieck/pi-tuedern@77ae94a` (or your previous known-good commit). Disable automatic repair immediately by removing the config opt-in or setting `PI_HARNESS_AUTOMATIC=0` before restarting Pi. Git refs must be reachable and Pi package installation may require network; retain a local archive for offline rollback. Test the rollback in the target repository before relying on it.

CI at `f36d306` completed successfully (GitHub Actions run 40188292148), and local fixture contracts passed when invoked independently from their project roots. A disposable React fixture with a syntax error made its stand-alone `./scripts/verify` exit 1 without Pi. CI runs `npm run verify` and all three contracts against the locked Pi 1.4.0 declarations, but is not protected-policy enforcement or a real Pi runtime compatibility matrix. GitHub's branch-protection API reports `main` unprotected (404); the repository rulesets API lists no rulesets. A workflow that runs on push is not a required protected check. This cannot protect policy files against agent edits. Additional gaps: no CI compatibility matrix, no published npm package, no protected-policy guarantee, no pilot in three real repositories. Verification records and terminal task summaries are JSON-schema validated. `node tests/interruption-smoke.mjs` confirms in real Pi RPC that an abort before settlement writes a `cancelled` summary with zero attempts. It also kills Pi during a running check: an in-progress state entry survives, and restarting the same session writes an `error` summary for that execution before a later prompt starts a new execution. `npm run verify` passed (12 tests), and the real Pi interruption smoke passed locally. Recovery requires reopening the same session with automatic mode and evidence recording enabled; no record can be written while the process is dead, and a crash before the in-progress entry is persisted or between recovery summary writing and clearing the marker can still leave missing or duplicate evidence. A recovered attempt has no completed attempt record or trustworthy check result; its summary counts the started attempt and reports `error`, **not** success. `node tests/resume-smoke.mjs` confirms that when a later handler suppresses continuation, `agent_settled` now records a terminal `failed` summary (the repair count is a requested continuation, not proof it ran). If the process crashes before this notification, the summary may still be missing. Do not announce a release gate or product acceptance from this smoke evidence.
